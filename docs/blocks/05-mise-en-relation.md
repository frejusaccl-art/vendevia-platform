# Étape 6 — Mise en relation maîtrisée

Le propriétaire choisit le mode de conversation : réponse écrite, rappel dans une fenêtre choisie ou préparation d’un rendez-vous. L’interface montre explicitement ce qui sera transmis : intention, contexte du bien, rythme et question ouverte.

Aucune option ne déclenche un contact silencieux. La confirmation est locale, lisible et modifiable. La route est `/maison/projet/mise-en-relation`.
